# Pruebas de Aceptación - QuestForge

Este documento registra las pruebas de aceptación para validar que la plataforma cumple con los requisitos básicos del sistema.

---

### Prueba 1: Verificación del nombre de la aplicación
* **Qué se comprueba:** Comprobar que la página principal muestra claramente el nombre "QuestForge".
* **Resultado esperado:** El título o encabezado principal de la interfaz web muestra de forma visible e identificable el texto "QuestForge".

### Prueba 2: Existencia de la sección de mods
* **Qué se comprueba:** Comprobar que existe una sección dedicada a los "mods" (modificaciones) dentro de la navegación.
* **Resultado esperado:** Se encuentra disponible un menú o sección titulada "Mods" que permite acceder al listado de modificaciones.

### Prueba 3: Existencia de la sección de servidores
* **Qué se comprueba:** Comprobar que existe una sección dedicada a los servidores de juego.
* **Resultado esperado:** Se visualiza claramente un apartado o sección de "Servidores" donde se pueden consultar los servidores activos o disponibles.

### Prueba 4: Estructura de información de cada mod
* **Qué se comprueba:** Comprobar que cada mod listado cuenta obligatoriamente con su nombre y una descripción detallada.
* **Resultado esperado:** Al visualizar cualquier elemento en la sección de mods, la tarjeta o vista detalle muestra de forma legible tanto el nombre del mod como un texto descriptivo.

### Prueba 5: Organización y legibilidad de la información
* **Qué se comprueba:** Comprobar que la información general de la interfaz está organizada, es intuitiva y se entiende fácilmente.
* **Resultado esperado:** Los elementos visuales están alineados, las fuentes son legibles y la distribución de las secciones permite una navegación fluida.
