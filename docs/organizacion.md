# Organización del proyecto QuestForge

## 1. Objetivo del proyecto

QuestForge es una propuesta académica de una plataforma web para organizar y compartir mods y servidores personalizados de videojuegos independientes. Se utiliza como caso práctico para estudiar la colaboración en el desarrollo de software.

## 2. Herramienta seleccionada

El equipo utiliza GitHub como repositorio compartido para guardar archivos y registrar cambios, y GitHub Projects para organizar las tareas, asignar responsables y visualizar el avance del trabajo.

## 3. Metodología Kanban

El tablero permite visualizar las tareas según su estado:

- **Backlog:** tareas pendientes de organizar o priorizar.
- **Todo:** tareas preparadas para comenzar.
- **In Progress:** tareas que se están realizando.
- **In Review:** tareas entregadas para revisión, si esta columna está habilitada.
- **Done:** tareas revisadas y aceptadas.

Las tareas avanzan entre columnas según el trabajo real de cada integrante.

## 4. Distribución de responsabilidades

- **Coordinación:** organizar el tablero, documentar el proceso y revisar las entregas.
- **Página principal:** preparar una página HTML sencilla para presentar QuestForge.
- **Catálogo de mods:** documentar ejemplos de mods, sus videojuegos, versiones y estados.
- **Versionado:** explicar cómo se identifican las versiones y registran los cambios.
- **Pruebas:** documentar comprobaciones para verificar que los requisitos se cumplen.

## 5. Colaboración y revisión

Cada integrante trabaja en la tarea que tiene asignada. Los cambios pueden presentarse mediante Pull Requests para que otro integrante los revise antes de incorporarlos a la rama principal.

El coordinador comprueba que las entregas cumplan los requisitos, solicita correcciones cuando sea necesario y marca las tareas como terminadas una vez aceptadas.

## 6. Conclusión

GitHub y GitHub Projects permiten centralizar el trabajo, distribuir responsabilidades y conocer el estado de las tareas. La metodología Kanban ayuda a identificar qué está pendiente, qué está en desarrollo y qué ya fue revisado.
